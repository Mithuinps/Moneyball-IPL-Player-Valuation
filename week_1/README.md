# Week 1 - IPL Data Exploration

## Project Title
Moneyball: IPL Player Valuation

## Objective
To analyse IPL player performance and auction prices using Python and data visualization.

## Datasets
- Auction.xlsx
- Top_100_batsman.xlsx
- Top_100_bowlers.xlsx
- matches.csv

## Activities Completed
- Loaded all four datasets using Pandas.
- Explored dataset dimensions and column names.
- Analysed the top 5 expensive auction players.
- Identified the top 5 batsmen by runs.
- Identified the top 5 bowlers by wickets.
- Analysed the top 10 teams by match wins.
- Identified Mumbai Indians as the team with the most wins in the dataset.

## Tools Used
- Python
- Google Colab
- Pandas
- GitHub

## Conclusion
The IPL datasets were loaded and explored successfully.
Player performances, auction prices, and team wins were analysed.
Mumbai Indians recorded the highest number of wins in the available dataset, with 109 victories.
