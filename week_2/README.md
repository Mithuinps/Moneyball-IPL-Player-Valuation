# Week 2 - Know Your Data

## Project Title
Moneyball: IPL Player Valuation

## Objective
To understand the structure and quality of IPL datasets.

## Activities
- Inspect dataset dimensions.
- Identify column names and data types.
- Check missing values.
- Check duplicate records.
- Display the first five rows of each dataset.

## Datasets
- Auction data
- Top 100 batsmen statistics
- Top 100 bowlers statistics
- IPL match data

## Tools Used
- Python
- Google Colab
- Pandas
- GitHub

## Expected Outcome
Understand the datasets and identify data quality issues before further analysis.
